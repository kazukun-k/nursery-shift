# 📛 保育士シフト管理・作成システム

保育士の時間帯別必要人数を自動計算し、園独自の変則ルールを AI (Gemini) が解釈、そして職員の勤務可能時間帯や上限日数に基づきシフト表を自動生成・Excel出力するWebアプリケーションです。

## 🌟 主な機能

1. **時間帯別の必要保育士数計算**
   - 園児の年齢（0歳児、1-2歳児、3歳児、4歳以上児）ごとの配置基準に基づき、時間帯別の必要人数を自動計算。
2. **AI (Gemini) による園独自ルールの解析**
   - 「7-9時は全学年合同保育とする」「17時以降は乳児・幼児の2クラスにして最低1人ずつ配置する」などの複雑な独自ルールを日本語で入力するだけで、Gemini APIが解析して配置基準に反映します。
3. **シフトの自動生成 (簡易ソルバー)**
   - 登録された職員の雇用形態、月上限日数、希望時間帯（早番、中番、遅番、全日）、時短希望などの条件を考慮し、1ヶ月分のシフト表を自動生成します。
4. **Excelファイルの出力**
   - 生成されたシフト表を、そのまま印刷・配布できる美しいデザインのExcel（`.xlsx`）形式でダウンロードできます。

## 🚀 ローカルでの実行方法

1. 必要なライブラリのインストール:
   ```bash
   pip install -r requirements.txt
   ```
2. アプリケーションの起動:
   ```bash
   streamlit run app.py
   ```

5. **「Deploy!」** をクリックすると、数分で世界中に公開されます。
